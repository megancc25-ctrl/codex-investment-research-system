# NQ-Sentinel Pro Hybrid

Market-only research system for US Nasdaq-100 and semiconductor risk. The GitHub runner processes **public market data only**; private holdings stay in a local Obsidian vault.

**Status:** research prototype. Not live trading, not an independently verified market data feed, and not validated for investment execution. See `nq_sentinel_pro/README.md` for installation and limitations.

Never upload brokerage statements, account values, private portfolio configurations or an Obsidian vault to this public repository.
