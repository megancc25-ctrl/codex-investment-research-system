# CRS 1.0 第三阶段质量审计

## 结论

第三阶段修正只涉及 CRS 引擎及其报告、采集和测试。七大模块、CRS 模块权重（15/15/10/20/20/10/10）、固定阈值、60/40融合以及 NQ-Sentinel 原有权重/规则均未调整。状态仍为 `PROVISIONAL_RESEARCH_ONLY`；本阶段没有新增数据源，没有伪造 MOVE、市场广度、连续 Repo 或 CDX 观测，也没有进行历史危机回测或生成交易指令。

修复指标级覆盖率、市场代理来源绑定、三资产共同日期和状态确认的最大日历间隔。完整评分只有在全局指标覆盖率至少85%、credit与liquidity模块可用、全部关键指标有效时才发布。缺失指标不会填零，也不会由同组其他指标增加覆盖数。

## P0-1 覆盖率口径

- `metric_coverage_pct` = 有效配置指标数 / 配置指标总数。
- `group_coverage_pct` = 至少一个有效指标的组数 / 配置指标组数；另保留 `weighted_group_coverage_pct` 以便与原有模块加权口径诊断比较。
- `weighted_module_coverage_pct` = 各模块有效指标覆盖率按现有模块权重汇总。
- 各模块逐项输出指标总数、有效数、缺失数、指标覆盖率和组覆盖率。
- `data_coverage_pct` 兼容字段现在与未加权全局指标覆盖率一致；发布门槛用未舍入指标覆盖率。
- 模块评分仍使用原七模块与组内最高值聚合。组分数不将缺失指标当零，也不为其记为有效；但完整总分门槛以指标数量为准，降低部分缺失被组覆盖率掩盖的问题。

### 修改前后覆盖率对比样例

以下是测试夹具的结构性示例，不是真实市场数据：权益模块 Drawdown 组有 NDX 与 SOX 两项；只提供 NDX，缺少 SOX，其余测试配置项完整。

| 口径 | 修改前 | 修改后 |
|---|---:|---:|
| Equity Drawdown组覆盖 | 100% | 100% |
| Equity指标覆盖 | 未独立显示（会由一个有效组成员掩盖） | 5/6 = 83.33% |
| 全局指标覆盖 | 未计算 | 25/26 = 96.15% |
| 全局组覆盖 | 加权组口径可能仍满覆盖 | 组覆盖独立显示为100% |
| 分数发布 | 旧85%组覆盖口径 | 仍需 >=85%指标覆盖并满足全部关键门槛 |

因此，组覆盖可用于描述“组中至少有一项可用”，不再被解释成该组所有配置指标都齐全。

## P0-2 来源与哈希绑定

- 每个价格证券用 `yahoo:<ticker>` 建立独立 `source_id`，并在采集诊断中单独保留 ticker、source、观察日期、检索时间、质量、许可状态和SHA-256。
- 派生指标从其输入证券的 metadata 显式取得 provenance；删除了按 source 字符串前缀/包含关系模糊匹配来源的路径。
- 复合三资产/相关性指标保存组件 source_id、ticker、hash、检索时间、区间与观察数；来源不足时标 `UNKNOWN`。
- yfinance 不提供本实现可存档的原始供应商响应字节。本阶段的 `raw_sha256` 是采集到的规范化日期/收盘价快照哈希，不宣称是供应商HTTP原始响应哈希；严格原始字节审计需改用可归档的官方接口/数据许可源。

## P1-1 日期对齐

- 三资产20日收益率只用三条序列的共同有效日期，并要求至少21个共同正价格日期；零、负数和缺失日不进入共同样本。
- 相关性取相同共同价格日期产生的20个日收益率，并保存窗口起止日期和样本数。
- 共同窗口不足时，两个同步下跌特征显式标记 `INSUFFICIENT_DATA`，不输出假 `false` 或0分；告警也改为读取共同日期特征。
- 单资产特征仍可用各自序列，不声称其单资产窗口与其他资产对齐。

## P1-2 状态机时间间隔

- 保留升级两次报告确认、降级五次报告确认；两次候选报告之间最大允许间隔为4个日历日，配置位于 `crs_v1.json`。
- 超过间隔时从一次确认重新累计，同时保留上一次已确认的状态，不因历史过期直接回到L0。这里按“报告次数 + 最大日历间隔”执行，不使用交易所日历；状态元数据明确记录该确认口径。节假日导致的间距如超过4个日历日会重置。
- 状态历史保留每次 as-of、候选/状态、原因码、模块分数、触发模块、覆盖率和确认间隔。
- 数据不足继续输出 `INSUFFICIENT_DATA`，不会隐式降为L0。人工紧急覆盖仍单独走L4覆盖路径。

## 测试与验证

新增回归覆盖：组覆盖100%而指标覆盖低于100%、85%指标门槛与关键指标否决、不同证券来源时间/hash隔离、共同交易日期缺口、异常非正价格、共同样本不足显式状态、状态确认间隔重置、以及NQ-Sentinel权重不变。

运行命令和完整逐项输出见 `docs/CRS_PHASE3_TEST_LOG.txt`。本地离线测试不能证明实时源稳定、供应商授权完备、哈希对应未转换源字节或模型预测有效；不代表 GitHub Actions 运行成功。

## 仍未接入的数据及发布判定

市场广度、MOVE、连续 Repo 利率/成交量、CDX IG/HY仍缺自动可信来源。IEF仍是国债ETF代理，GLD是黄金ETF代理，美元指标仍非可靠ICE DXY全序列；HY/IG OAS仍有授权与历史发布版本限制。由于数个关键指标缺失，正常无人工数据输入时不得发布完整CRS评分，报告应显示 `DATA_INSUFFICIENT`。最终数据日状态仍应以真实采集日报为准。
