# ASWM 1.0 — 审计、设计和实施计划

日期：2026-11-26。授权规格：[GitHub Issue #5](https://github.com/megancc25-ctrl/codex-investment-research-system/issues/5)，已通过连接器实际读取；连续离线开发已获用户明确授权。

基线：`e172c8af873064414534a95074921ab217e53901`，FRIE分支转出`codex/aswm-1.0`。215项测试通过。既有未提交V3修改不属于本次交付，保持原样。

## 架构与映射

- FRIE事件/交易日历/收益、点时证据解析、授权与新鲜度、SQLite审计、回测基础函数直接复用，不新建采集器。
- SW01–SW08和原O01–O08主题相关，但新的阶段要求必须显式计算。SW09增加SOX/NDX、广度及半导体趋势；SW10改为半导体盈利、订单和毛利，不把原O10通用盈利上修冒充硬件确认。
- FRIE风险评分不变。ASWM为新模型和新版本证据，旧O系列证据不自动晋升SW判断。
- 当前仓库未找到可调用CRS。提供带as_of/有效期/质量的外部约束契约；缺失或严重风险均阻止仓位准入，不假装已连CRS。
- 三份输出独立：AI应用商业化/增长阶段、硬件需求订单利润传导、风险/估值/私人预算准入。BLOCKED不是增长阶段。
- 风险和机会不相减。NOT_VALIDATED恒定；所有交易、生产评分、外部发布和未经准入采集均关闭。

## 阶段规则（候选研究配置）

SW权重10/10/15/10/10/10/10/10/5/10。有效数量覆盖>=80%，同时报告有效权重及分数区间；未知权重不按零断言、不重新分配。关键要求缺失为UNKNOWN，已知未满足则保持较低阶段。

S1>=45且市场反应和至少一项独立商业化或信用证据通过；S2>=65且付费、推理/硬件、现金流、信用和半导体盈利企稳；S3>=80且两个不同季度可比新披露、真实订单、盈利毛利、广度、估值和信用通过。市场确认需五个不同实际交易日；不得通过多次重复运行累计。阶段可倒退，失效不能被视为风险解除。

分数阈值不替代证据；每个阶段公开未满足/未知条件。无数字定义的经济判断使用带明确事实字段和来源的审核记录，不编造标准。

## 私人预算

只读本地忽略目录data/aswm/private.json。示例模板不含真实持仓/净值。总账户损失上限与新增仓位损失预算必须显式区分。费用/汇率/其他资产/不确定性/流动性缺失时显示未完成预算，不能默认零风险。预算数学空间不等于准入许可。历史减仓仅保留已完成标记，不生成重复减仓任务。

## 实施与验证

1. SW注册表、五核心模块、真实/代理/缺失/滞后/受限证据及确定性候选函数，先测试后实现。
2. 抽取并复用FRIE证据解析；ASWM状态、独立性、五交易日/季度持续性、三问分离和风险准入测试。
3. 私人配置预算、总账户/增量语义、过期和缺失测试；时间隔离滚动/留出与模块消融工具，合成验证不冒充真实市场回测。
4. 共用SQLite中的独立版本历史/转换记录，稳定重复去重；共享本地HTTP服务与ASWM独立页面、日报栏目。
5. 所有旧测试和新增测试、HTTP/UI、CLI离线冒烟、代码复核、限定文件提交和明确GO/NO-GO。

外部数据许可、真实历史有效性、CRS部署、付费与生产发布为外部依赖，不能用测试通过代替。
