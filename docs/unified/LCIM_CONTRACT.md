# LCIM 1.0 离线契约与验收

现有基线 e2e23e8：LCIM 21项注册与部分计算，FRIE审计、MRM、PIT回测/告警复用；CRS/NQ为独立既有仓库。原F03/F04/F07/F08/F14/F18及冻结模型不改。输入统一 source/用途授权、available_at/observed_at/published_at/retrieved_at/vintage、单位、期限和universe，缺失 UNKNOWN，首次可得时刻之后才能参与；修订按时点选择，不得把抓取时刻当作首次可得。默认禁采集/缓存/发布。

候选规则：债务/GDP及M2 P95、债务/市值 P90；相对历史峰值下跌5%观察，10%且独立信用或广度证据升级；IPO融资强度P90。分位仅使用至少120个月已可得的可比样本；同日YTD只与同日YTD比较。积累/去杠杆/发行旺盛/融资失败四状态互不相减；统一经济事件不重复投票。不创建新的生产评分。
